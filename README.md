# Payroll & Business Automation System

A web-based payroll and business automation application developed using **ASP.NET Core, C#, Entity Framework Core and SQL Server**.

## 🚀 Features

* Employee Management
* Attendance Management
* Leave Management
* Payroll Processing
* Salary Calculation
* Employee Salary Details
* Reports
* User Authentication & Authorization

## 🛠️ Technologies

* ASP.NET Core
* C#
* Entity Framework Core
* SQL Server
* HTML, CSS, JavaScript
* Bootstrap

## ▶️ How to Run

1. Clone the repository.
2. Open the project in Visual Studio.
3. Configure the SQL Server connection string.
4. Update the database.
5. Run the application.

```bash
git clone YOUR-GITHUB-REPOSITORY-URL
```
